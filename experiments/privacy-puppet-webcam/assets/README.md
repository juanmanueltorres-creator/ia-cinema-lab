# MPFB blink test fixture

`mpfb-blink-test.glb` is a separate clay head, **not Liam, Kofi or Yuki**. It has no jaw, teeth, tongue, hair, body or production skin. Its only expression channels are `!ex-eyeBlinkLeft` and `!ex-eyeBlinkRight`. Do not use it to certify mouth quality.

Generated locally with Blender 5.2.2 LTS and MPFB2 2.0.18 using `../tools/build-blink-fixture.py`. Each target moves 718 original head vertices. The GLB is 340,040 bytes; SHA-256: `81c9a4c9d735c7feab249cc61c9ea4ad3b92fae9fbac1d1d17030c5be868930a`.

## Rebuild on Windows

The executable below was checked locally. Requires the enabled MPFB2 extension. Download only the two CC0 targets to a temporary directory; no global asset-pack installation is needed for this fixture.

```powershell
$targets = Join-Path $env:TEMP 'ia-cinema-faceunits01'
New-Item -ItemType Directory -Force $targets | Out-Null
$source = 'https://raw.githubusercontent.com/makehumancommunity/extra-targets/7eaba3453134385bb5ea9811ef0b33b85b4b556d/assets/faceunits01/targets/faceunits'
'eyeBlinkLeft','eyeBlinkRight' | ForEach-Object {
  Invoke-WebRequest "$source/$_.target" -OutFile (Join-Path $targets "$_.target")
}
& 'A:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --python-exit-code 1 --python experiments/privacy-puppet-webcam/tools/build-blink-fixture.py -- --targets $targets --output (Join-Path $targets 'mpfb-blink-test.glb')
```

The exporter refuses an existing output, missing targets, or empty eyelid deltas. It runs in a fresh headless process, never opens/saves a `.blend`, and never targets an imported GLB. Open the generated output with **Mi GLB** to compare it before intentionally replacing this fixture.
